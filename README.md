# psihi
Психологические тесты
Целевая аудитория: пользователи, которым необходима психологическая помощь и поддержка

Сущности: User (имя, возраст, пол), Test (название, описание, категория (тревожность/депрессия/стресс и т.д.), инструкция), Question (тест, текст, порядковый номер), 
QuestionOption (вопрос, текст, количество баллов), TestResult (пользователь, тест, дата, сумма баллов, текстовая интерпретация).
Экраны: список доступных тестов, прохождение теста (вопрос за вопросом), история результатов с графиком.
Сеть: загрузка тестовых вопросов.
Уведомления: напоминание пройти тест раз в неделю.
Медиа: опционально – фото перед тестом.
Анимация: пнимированная шкала результатов (лепестковая диаграмма) после завершения.
